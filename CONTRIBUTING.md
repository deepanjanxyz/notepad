# Contributing

Thanks for helping improve Elite Memo Pro. A few guidelines keep things consistent.

## Code

- Keep the `:domain` module free of Android dependencies.
- Prefer one focused use case per operation.
- Name values instead of writing them inline — colours, sizes, timings, limits.
- Keep lines within 120 columns.
- Keep functions small and single-purpose, and give public declarations a short KDoc comment.

## Tests

Keep the unit tests green, and add one when you change behaviour.

## Commits

Use Conventional Commits — `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`.

## Conduct

By taking part you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
